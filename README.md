# Marketing-Digjital
AdVantage- Digital Marketing Management System

AdVantage is a digital marketing platform that helps businesses manage campaigns, analytics, content creation, scheduling, and audience engagement in a simple and effective way.

Some of our features:
  User Authentication/Authorization
  Campaign Management
  Analytics Dashboard
  Content Scheduling
  Audience Reports
  Notification System
  Admin Panel

Technologies Used 
  Frontend: React.js, Tailwind CSS
  Backend: Node.js, Express.js
  Database: MySQL / Prisma for ORM

Backend setup: 
 cd backend
 npm install
 npm run dev

Frontend setup:
 cd frontend
 npm install
 npm run dev

API Documentation is available:
Download this file and import in your Postman account:
